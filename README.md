# SupportHub

A full-stack role-based ticketing system built with Django REST Framework and a custom frontend.

## Features
- JWT Authentication
- Role-based access (Customer, Staff, Manager)
- Ticket creation and management
- Comment system
- Filtering and search
- Clean UI dashboard

## Tech Stack
- Django + DRF
- SQLite
- HTML/CSS/JS frontend

## How to Run

### Backend
cd backend
python manage.py runserver

### Frontend
cd frontend
python3 -m http.server 5500
